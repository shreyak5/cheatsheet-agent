L1 · Introduction & Probability recap

  • IT = art of redundancy: remove it when it hurts (compression/source coding), add it when it helps (channel coding). Info & statistics = two sides of one coin.
  • Repetition R3 over BSC(f): decode = majority vote (Bayes: ŝ=argmaxs P(r|s)P(s)). pb = 3f²(1−f)+f³ ≈ 3f²: error O(f)→O(f²), but rate ÷3. Shannon: error-free comms at non-zero rate possible (rate < C).
  • Source code goals: short + easily decodable; frequent symbols → shorter words.
  • Logs: logb(xy)=log x+log y; log xn=n log x; logbx=logax/logab; log 1=0; log(x+y) does NOT simplify. log≡log2; ln 2≈0.69.
  • Convex-down (∪, f(λx₁+(1−λ)x₂) ≤ λf(x₁)+(1−λ)f(x₂)): prove via f″≥0, affine maps f(Ax+b), non-neg. weighted sums. log and −x log x are concave (∩).
  • Jensen: f convex-down ⇒ E[f(x)] ≥ f(E[x]) (reversed for concave, e.g. E[log x] ≤ log E[x]).
  • RV X:Ω→E measurable fn; P(ω)≥0, P(Ω)=1. Discrete: Σp=1; continuous: ∫p=1 (density may exceed 1, ∫abp ≤ 1). Ep[f]=Σp(x)f(x); Var=E[(X−µ)²]=E[X²]−µ². i.i.d. = independent + identically distributed.
  • Gaussian: N(µ,Σ): p=(2π)−d/2|Σ|−1/2exp(−½(x−µ)ᵀΣ⁻¹(x−µ)). 68.3/95.5/99.7% within 1/2/3σ.
  • Limits: (ε,δ) def; limx→0+ ln x=−∞.
  • Limit defs: limx→pf=L iff ∀ε ∃δ: 0<|x−p|<δ ⇒ |f−L|<ε. Infinite limit: ∀N ∃δ ⇒ f>N. At infinity: ∀ε ∃c: x>c ⇒ |f−L|<ε (e.g. 1/x²→0).
  • Sets/functions: |S| cardinality, ⊂ subset, Sᶜ complement. Injective: f(x₁)=f(x₂)⇒x₁=x₂; bijective = injective + onto ⇒ invertible.
  • RV ingredients: sample space Ω (all outcomes), event space E (measurements), P. Ex: 3 coins, X=#heads, Ω={H,T}³, E={0,1,2,3}. Notation: X RV, x realisation, 𝒳 alphabet, X∼p(x), pi=p(xi).
  • Source-coding example: one-hot = 3 bit/pixel; variable length (Blue→0, Red→10, White→11) = 1.56 bit/pixel. BSC: P(y=0|x=0)=P(y=1|x=1)=1−f; P(flip)=f. Beyond Shannon: multi-variable interactions H(Z|X,Y), I(X;Y;Z).

L2 · Entropy & source coding theorem

  • Surprisal h(x)=log(1/p(x)). Entropy H(X)=Σp(x)log(1/p(x))=E[h(X)]. bits (log₂) / nats (ln). 0log0=0.
  • Binary entropy H₂(p)=−p log p−(1−p)log(1−p); max 1 bit at p=½. (p=0.1→H₂=0.47; h(0.2)=2.3 bit; h(0.1)=3.3 bit.)
  • Bounds: 0 ≤ H(X) ≤ log|X|. Min: Kronecker delta; max: uniform.
  • Independent: h(x,y)=h(x)+h(y); H(X,Y)=H(X)+H(Y) (additive).
  • Worked (mock Q1): p={.25,.25,.2,.2,.1}: H=2(.25·2)+2(.2·log5)+.1·log10=1+0.929+0.332=2.261 bit. Lengths ⌈−log p⌉={2,2,3,3,4}; Kraft Σ2−ℓ=.25+.25+.125+.125+.0625=0.8125≤1 ⇒ a prefix code with these lengths exists (Kraft ≤1 ⇔ lengths are realisable by a prefix code). L=1+1.2+.4=2.6 bit ≥ H=2.261 (SCT/converse: L≥H for any code; Huffman is optimal).
  • Shannon axioms: i(1)=0; di/dp ≤ 0; i(pq)=i(p)+i(q) ⇒ i(p)=−logbp (unique).
  • Guessing games: uniform ⇒ h(x)=#yes/no questions (63-game: 6 bits). Submarine: total info always log 64=6 bit regardless of when hit. Info = probability-mass exclusion (Hartley). Design experiments with evenly probable outcomes.
  • Differential entropy H(X)=−∫f log f dx. Discretising: H(XΔ)=−Σ Δf(xi)log f(xi) − log Δ → diverges; drop −log Δ. Can be negative; U[0,a]: H=log a; 2H=volume.
  • Gaussian: surprisal h(x)=ln(σ√2π)+½((x−µ)/σ)² = ln σ + MSE/2σ² + C. H = ½ln|2πeΣ| (1D: ½ln(2πeσ²)=½(1+ln 2πσ²)). D-dim: derived via E[(x−µ)ᵀΣ⁻¹(x−µ)]=tr(Σ⁻¹Σ)=D.
  • Meanings of H: avg surprisal E[h(X)]; min expected #yes/no questions (exact for uniform, asymptotic otherwise); min compressed length per symbol; generalised variance (how quickly p fills the space; Gaussian: grows with ln|Σ| / avg MSE); H(X)=log|X|−D(p‖u). Continuous: only differential H (not invariant, can be <0).
  • Code: C:X→D*; ℓ(x) length; L=E[ℓ(x)]. Binary |D|=2, d-ary |D|=d. Uniform: L=log|X| (raw bit content); if |X| not power of 2 use ⌈log|X|⌉ (“extra bit”). Ignoring 2% rare symbols saved 6→5 bits (lossy).
  • wLLN: Ȳn=(1/n)ΣXi: E=µ, Var=σ²/n; Ȳn →P µ: lim Pr(|Ȳ−µ|<ε)=1. High-dim Gaussian: points lie in a thin shell, Std(r²)/E[r²]=O(1/√n)→0.
  • AEP: −(1/n)log p(x₁…xn) → H(X) (via wLLN on −(1/n)Σlog p(xi)). All typical samples ~equally probable.
  • Typical set Aε(n): 2−n(H+ε) ≤ p(xⁿ) ≤ 2−n(H−ε). Props: (1) xⁿ∈A ⇒ |−(1/n)log p(xⁿ)−H|≤ε, p≈2−nH; (2) P(xⁿ∈A)>1−ε; (3) |A| ≤ 2n(H+ε) [1=Σp ≥ ΣAp ≥ |A|2−n(H+ε)]; (4) |A| ≥ (1−ε)2n(H−ε).
  • Coin intuition (bias p): pr(1−p)n−r favours few 1s, C(n,r) favours n/2 ⇒ balance at r/n=p. Only ≈2nH of |X|ⁿ strings happen. Entropy = log(#events that almost always happen)/log(#possible) = fraction of volume; Gaussian H ∝ log V + C.
  • Source Coding Thm (SCT): Xⁿ i.i.d.∼p; ∀ε>0, large n ⇒ ∃ invertible code with E[(1/n)ℓ(Xⁿ)] ≤ H(X)+ε. Converse: no invertible code has L<H(X). Achievability proof: flag bit 0 + index in A (ℓ≤1+⌈log|A|⌉≤n(H+ε)+2) else flag bit 1 + index in Xⁿ (ℓ≤n log|X|+2). ⇒ L ≤ n(H+ε′), ε′=ε+ε log|X|+2/n. Converse: subset C⊂A with |C|≈2n(H−κ) has P(C)≈2−nκ→0.

L3 · Symbol codes, KL, MLE

  • No free lunch: cannot shorten all strings: lossy (collisions) or lossless (some strings longer).
  • Code types (nested): nonsingular (x≠x′ ⇒ C(x)≠C(x′)) ⊃ uniquely decodable (extension C*(x₁…xn)=C(x₁)…C(xn) nonsingular) ⊃ prefix (instantaneous; no codeword is a prefix of another; leaves of a tree). Morse: nonsingular, not UD. Invertible ≠ easy to invert (RSA).
  • Kraft: prefix code lengths satisfy ΣiD−ℓi ≤ 1; conversely lengths satisfying it ⇒ ∃ prefix code. (Also holds for UD codes.) Proof: ≤Dℓmax leaves; word of length ℓi kills Dℓmax−ℓi leaves. “Codeword supermarket” budget.
  • Optimal lengths (Lagrange L=Σpiℓi+λ(ΣD−ℓi−1); ∂L/∂ℓi=pi−λD−ℓiln D=0, λ=1/ln D): ℓi*=−logDpi, L*=HD(X); ∂²L=D−ℓln D≥0 ⇒ global min. Entropy = min length of any symbol code. Duality: lengths ℓ ⇒ implicit probs p∝D−ℓ. Non-integer ⇒ round up ℓ=⌈−log p⌉ (still satisfies Kraft).
  • Lagrange: min f(x) s.t. g(x)=0: L=f+λ·g, solve ∇x,λL=0 (k+c equations).
  • Huffman: repeatedly merge the two least probable symbols into a tree node until one remains; read codes root→leaf. Optimal: L(C*)≤L(C′) for any UD code. Ex: p={.25,.25,.2,.15,.15}→ℓ={2,2,2,3,3}.
  • Cross-entropy H(p,q)=−Σp log q = expected length of q-optimal code on p-samples. KL D(p‖q)=Σp log(p/q)=H(p,q)−H(p) = extra cost of wrong code.
  • Chain of reasoning (exam): ℓ*=−log p ⇒ L*=H; wrong q ⇒ L=H(p,q)=H(p)+D(p‖q); L≥H follows from Gibbs (D≥0). ML on data ⇔ min D(p‖q) ⇔ min code length.
  • Gibbs: D(p‖q)≥0, =0 iff p=q. Proof: −D=Σp log(q/p) ≤ log Σq = 0 (Jensen, log concave). KL convex in q; asymmetric (not distance); =∞ if ∃x: q=0, p>0. D(p‖u)=log|X|−H(p) ⇒ H≤log|X|. Ex: D(p₂‖p₃)=∞.
  • Continuous KL = Σ Δf log(f/g): log Δ cancels ⇒ ≥0.
  • Wrong-code ex: code for q={½,¼,⅛,⅛} (C={0,10,110,111}) costs 1.75 bit on q but 2.66 bit on p={0,⅓,⅓,⅓}. KL examples (a–d): D(p₁‖p₂)=0.25, D(p₂‖p₃)=∞, D(p₃‖p₂)=0.5, D(p₃‖p₁)=1 bit.
  • Prefix tree facts: complete D-ary tree has Dℓmax leaves; adding a codeword removes all its descendants. Huffman ex: a→00 b→10 c→11 d→010 e→011.
  • SCT summary (symbol codes): ∀p(x) ∃ prefix code with L close to H (achievability), none with L<H (converse). C&T proves SCT via lossless block code; MacKay via lossy (error only outside A).
  • KL of Gaussians: D(p‖q)=½[σp²/σq² −1 −ln(σp²/σq²) + (µp−µq)²/σq²]; H(p,q)=½ln2πσq²+(σp²+(µp−µq)²)/2σq². Narrow Gaussians: KL grows faster with Δµ.
  • MLE: θ*=argmax p(x;θ); i.i.d.: L(θ)=(1/n)Σln p(xi;θ) → Ep[ln p(x;θ)]. Gaussian mean: µ*=(1/n)Σxi.
  • Good compressor = good predictor: q(x)=2−ℓ(x)/z, z=Σ2−ℓ≤1 (Kraft number). Ep[ℓ−ℓ*]=log(1/z)+D(p‖q) ≥0; =0 iff Kraft equality & p=q.

L4 · Joint entropy & mutual information

  • Joint probs: marginal p(x)=Σyp(x,y); cond. p(x|y)=p(x,y)/p(y); product p(x,y)=p(x|y)p(y); sum p(x)=Σp(x|y)p(y); Bayes p(x|y)=p(y|x)p(x)/p(y).
  • Independence: X⊥Y ⇔ p(x,y)=p(x)p(y) (⇒p(X|Y)=p(X)). Cond.: X⊥Y|Z ⇔ p(x,y|z)=p(x|z)p(y|z). Conditioning can create/destroy independence: Y=f(X),Z=g(Y): X⊥̸Z but X⊥Z|Y; X,Y fair, Z=X+Y mod 2: X⊥Z but X⊥̸Z|Y.
  • Bayesian net: p(X)=Πkp(Xk|pak). Markov chain X−Y−Z: p(Xt|Xt−1…X₁)=p(Xt|Xt−1) (order p: last p). X−Y−Z ⇒ X⊥Z|Y.
  • Joint H(X,Y)=−Σp(x,y)log p(x,y) (symmetric). Cond. H(X|Y)=Σyp(y)H(X|Y=y). Props: 0 ≤ H(X|Y) ≤ log|X|; =0 if X=f(Y); X⊥Y ⇒ H(X|Y)=H(X).
  • Cond. KL: D(p(X|Y)‖q(X|Y))=Σyp(y)D(p(X|y)‖q(X|y)) ≥0.
  • Chain rule: H(X,Y)=H(X|Y)+H(Y)=H(Y|X)+H(X) (proof: p(x,y)=p(x|y)p(y), split log). Ex: H(X,Y)=2.25, H(X)=1, H(Y)=1.41, H(X|Y)=0.84, H(Y|X)=1.25.
  • Isomorphism (bijective f): H(X)=H(Y) in discrete (via both chain rules, H(X|Y)=H(Y|X)=0); I(X;Y) invariant even in continuous.
  • Stationary process: p(X₁..Xt)=p(X1+s..Xt+s). Entropy rate h₁=lim(1/n)H(X₁..Xn) = innovation h₂=lim H(Xn|X₁..Xn−1) (stationary). More conditioning ⇒ less entropy; H(Xn|Xn−t..Xn−1) decreases to h at t=Markov order. Coin-in-box (flip w.p. p): h=H₂(p). Stream codes: Lempel-Ziv (zip).
  • Mutual information I(X;Y)=Σp(x,y)log[p(x,y)/(p(x)p(y))] = H(X)+H(Y)−H(X,Y) = H(X)−H(X|Y) = H(Y)−H(Y|X) = D(p(X,Y)‖p(X)p(Y)). Symmetric; ≥0; =0 iff X⊥Y; I ≤ min{H(X),H(Y)} (discrete). Notation: I(X,Y;Z) joint vs ; separator.
  • Information doesn't hurt: H(X|Y) ≤ H(X) (avg; H(X|Y=y) can exceed H(X)).
  • Joint-table method: get p(x),p(y) by summing rows/cols; H(X|Y)=Σyp(y)H(X|y); check H(X|Y)=H(X,Y)−H(Y). Die ex: X=even, Y=>3 ⇒ joint = intersections of preimages p(X=x,Y=y)=p(ω∈X−1(x)∩Y−1(y)).
  • Inequalities cheat-list: H(X,Y) ≤ H(X)+H(Y) (eq. iff ⊥); H(X,Y) ≥ max(H(X),H(Y)); H(X|Y)≥0; I(X;Y)≥0; I(X;Z)≤I(X;Y) if X−Y−Z; I(X;Y)≤H(X) (discrete); for continuous H can be <0 but I stays ≥0.
  • CMI I(X;Y|Z)=H(X|Z)+H(Y|Z)−H(X,Y|Z)=H(X|Z)−H(X|Y,Z)=D(p(X,Y|Z)‖p(X|Z)p(Y|Z)) ≥0; =0 iff X⊥Y|Z.
  • MI chain rule: I(X,Y;Z)=I(X;Z)+I(Y;Z|X).
  • Data processing ineq.: X−Y−Z ⇒ I(X;Z) ≤ I(X;Y) (I(X;Y,Z)=I(X;Z)+I(X;Y|Z)=I(X;Y)+I(X;Z|Y), last =0).
  • MI properties summary: I(X;Y)=E[log p(x,y)/p(x)p(y)]; I(X;X)=H(X); I(X;f(Y)) ≤ I(X;Y) (DPI); reduction of uncertainty in X after knowing Y; Gaussian I depends only on correlation ρ; zero ρ ⇏ I=0 in general.
  • Venn: H(X)↔µ(A), H(X,Y)↔µ(A∪B), H(X|Y)↔µ(A\B), I↔µ(A∩B). Co-information I(X;Y;Z)=H(XYZ)−H(XY)−H(YZ)−H(XZ)+H(X)+H(Y)+H(Z) can be negative (signed measure).
  • Gaussian MI: I(X;Y)=−½ln(1−ρ²)=½ln(σyy/σ²y|x) (explained variance). ρ=0 ⇒ I=0 only for Gaussians; uncorrelated ≠ independent in general; MI = generalised dependence.
  • MI & prediction (Barber-Agakov): I(X;Y)=H(Y)+E[log p(y|x)] ≥ H(Y)+Ep(x,y)[log qθ(y|x)] (Gibbs). Equality if p(y|x)∈Q; MI upper-bounds best predictor.

L5 · Channel coding

  • DMC: input alphabet X, output Y, p(y|x); extended p(yⁿ|xⁿ)=Πp(yi|xi). BSC(f): flips w.p. f; uniform input: I=1−H₂(f) (H(Y|X)=H₂(f), H(Y)=1).
  • Capacity C=maxp(x) I(X;Y); maximiser p*(x) = capacity-achieving dist. Interpretation: max rate (bits/use) at which info can be sent with vanishing error. Recipe: param. p(X=1)=α, write I(α)=H(Y)−H(Y|X), set dI/dα=0.
  • Noisy typewriter (|X|=|Y|=27, letter or 2 neighbours w.p. ⅓): H(Y)=log27, H(Y|X)=log3, I=log9 for uniform X; use every 3rd letter ⇒ error-free, C=log9. Pick non-confusable inputs (disjoint output sets). Counting: 2nH(Y)/2nH(Y|X)=2nI(X;Y) distinguishable inputs.
  • (n,K) block code: 2K codewords length n; rate R=K/n bits/channel use. Decoder ŝ=Dec(yⁿ) (+failure symbol). Mean block error pB=Σp(s)p(ŝ≠s|s); maximal pBM=maxsp(ŝ≠s|s); bit error pb.
  • Noisy channel coding thm: (1) ∀ε>0, R<C, large n ⇒ ∃ code of rate R with pBM<ε. (2) With pb acceptable, rates up to R(pb)=C/(1−H₂(pb)) achievable. (3) Rates above R(pb) not achievable.
  • Jointly typical set Jε(n): |−(1/n)log p(xⁿ)−H(X)|<ε, same for yⁿ, and |−(1/n)log p(xⁿ,yⁿ)−H(X,Y)|<ε. Props: (1) p(xⁿ,yⁿ)≈2−nH(X,Y); (2) Pr(J)→1 (union bound on complements); (3) |J| ≤ 2n(H(X,Y)+ε); (4) independent x̃ⁿ,ỹⁿ∼p(xⁿ)p(yⁿ): Pr(J) ≤ 2−n(I(X;Y)−3ε).
  • Proof ingredients: (a) random codes (2nR words ∼p(xⁿ); average ⟨pB⟩ easy; “weighing babies”: avg ≤δ ⇒ some code ≤δ); (b) typical-set decoder (success iff exactly one s with (xⁿ(s),yⁿ) jointly typical); (c) errors: xⁿ(s) not typical →0 (Prop 2), or other s′ typical ≤ (2nR−1)2−n(I−3ε) ≤ 2−n(I−R−3ε) →0 iff R<I−3ε (use p* ⇒ R<C−3ε); union bound; (d) expurgation: drop worst half of words ⇒ pBM ≤ 2pB, rate R′=R−1/n.
  • Repetition RN: R2 detects 1 flip, R3 corrects 1 flip. Parity: XOR = sum mod 2.
  • Worked: Z channel p(Y=0|X=0)=1, p(Y=0|X=1)=½. Uniform X: p(Y=0)=¾ ⇒ H(Y)=H₂(¼)=0.811; H(Y|X)=½·0+½·1=0.5 ⇒ I=0.311 bit. General α=p(X=1): p(Y=1)=α/2, I(α)=H₂(α/2)−α; dI/dα=½log[(1−α/2)/(α/2)]−1=0 ⇒ (1−α/2)=2α ⇒ α*=0.4, C=H₂(0.2)−0.4=log(5/4)=0.322 bit. BSC: C=1−H₂(f) at uniform input.
  • Bit-error tradeoff: allowing pb raises max rate to C/(1−H₂(pb)); pb→0 recovers C. Three regions: (1) any pb incl. 0 (R<C); (2) faster codes with pb>0; (3) prohibited. R3 over BSC: rate ⅓, pb≈3f².
  • Hamming encode ex: s=(d₁d₂d₃d₄); t=(p₁p₂d₁p₃d₂d₃d₄). Decode: compute z=Hr; if z≠0 flip bit at position (z₃z₂z₁)₂ [z₁=LSB]; read data bits 3,5,6,7. Detects 2 errors but mis-corrects them.
  • Hamming(7,4): n=2m−1=7, K=4 data, m=3 parity; 2⁴=16 codewords; layout p₁p₂d₁p₃d₂d₃d₄ (parity at positions 1,2,4). p₁=d₁+d₂+d₄, p₂=d₁+d₃+d₄, p₃=d₂+d₃+d₄ (mod 2).
  • Matrices: H∈Bm×n, column j = binary of j (LSB top): H=[1010101; 0110011; 0001111]. G∈BK×n: data columns = identity IK, parity columns = data rows of Hᵀ. t=Gᵀs mod 2; r=t+n mod 2; syndrome z=Hr mod 2=Hn (Ht=0). Syndrome = binary index of flipped bit (e.g. 110→bit 3). Corrects any single flip. Systematic = data bits first, parity last.
  • Hamming distance d=#differing bits; min distance t ⇒ corrects ⌊(t−1)/2⌋ errors (Hamming(7,4): t=3). Sphere packing; “perfect” = spheres fully packed.
  • Source-channel separation: optimal error-free rate for V through p(y|x) achieved by separate source code (compress to H(V)) + channel code. Summary: source coding: H = optimal compression; channel coding: I = optimal transmission.

L6 · Probabilistic inference

  • Descriptive vs inferential statistics (param. estimation, hypothesis testing). Frequentist: true fixed θ, repeated experiments. Bayesian: beliefs about θ (θ is an RV).
  • NHST: H₀ (null, “business as usual”) vs H₁. Rejection region R: x∈R ⇒ reject H₀. Can never “accept” H₀. Simple: point θ=θ₀; composite: region θ∈Θ₀; nested: H₀ fixes a parameter of H₁ (e.g. a=0 in y=ax+b).
  • Type I α=P(x∈R|H₀) (false positive; boy cried wolf). Type II β=P(x∉R|H₁) (false negative). Power=1−β. Bound α, maximise power.
  • Neyman-Pearson: for simple H₀:θ₀ vs H₁:θ₁, most powerful test of size α is R={x: pθ₁(x)/pθ₀(x) > k} with Pθ₀(R)=α. Proof: compare R vs R′ equal α; R\R′ has ratio>k, R′\R ratio<k, equal null prob φ ⇒ Pθ₁(R)>Pθ₁(R′).
  • LRT: Λ=supθ∈Θ₁pθ(x)/supθ∈Θ₀pθ(x); optimal for point (N-P) & monotone-LR composite (Karlin-Rubin); not always optimal. i.i.d.: log Λ=Σ[log pθ₁*(xi)−log pθ₀*(xi)] → nE[...]; θj* = MLE under each hypothesis. log Λ = frequentist evidence for H₁.
  • MI as LR: H₀: p=f(x)g(y) vs H₁: general. sup log pH₁=−nH(X,Y), sup log pH₀=−n(H(X)+H(Y)) ⇒ I(X;Y)=(1/n)E[log Λ]. Most info quantities are log-LRs.
  • Bayes: p(θ|D)=p(D|θ)p(θ)/p(D): posterior=likelihood×prior/evidence. Predictive p(D′|D)=∫p(D′|θ)p(θ|D)dθ. MAP θ=argmax p(D|θ)p(θ). Evidence p(D)=∫p(D|θ)p(θ)dθ=Ep(θ)[p(D|θ)] (“replace sups with sums”).
  • Gaussian posterior (prior µ∼N(µ₀,σ₀²), x∼N(µ,σ²)): µ₁=(σ₀²x+σ²µ₀)/(σ₀²+σ²), 1/σ₁²=1/σ₀²+1/σ².
  • Bayesian hypothesis test: p(H|D)=p(D|H)p(H)/p(D), p(D)=Σp(D|H)p(H). Posterior odds = Bayes factor BF=p(D|H₁)/p(D|H₀) × prior odds. BF≫1 ⇒ H₁; ≈1 inconclusive; ≪1 ⇒ H₀ (can support either). Coin ex: H₀:q=½ ⇒ p(D|H₀)=2−n; H₁:q∼U(0,1) ⇒ p(D|H₁)=h!(n−h)!/(n+1)!; BF=h!(n−h)!2n/(n+1)!.
  • Occam factor: p(D|H)≈p(D|wMP,H)×σw|D/σw = best-fit likelihood × Occam factor; small when large prior space but small fitting region. Complex models spread evidence thinly.
  • MDL (Shannon's razor): L(D)=L(Hi)+L(w*|Hi)+L(D|w*,Hi); choose min; trade-off complexity vs fit.
  • Worked LLR (mock Q4): H₀: exponential λ vs H₁: half-normal σ on x≥0 (both parametric families ⇒ composite, not nested (different families), so N-P does not directly apply: N-P guarantees optimal power only for simple vs simple; LR still “usually good”). MLEs: λ*=1/x̄, σ*²=mean(x²)≡x̄². log pλ*=−n ln x̄−n; log qσ*=(n/2)ln(2/(π x̄²))−n/2. log Λ = n[ln x̄ − ½ln(x̄²) + ½ln(2/π) + ½] (bars: mean(x) vs mean(x²)).
  • Coin vs die ex: H₀ Bernoulli(½) vs H₁ Bernoulli(1/6); data HHTTTTHTTHTTTTTHTTTT (5 heads/20): p(D|H₀)=2−20≈10−6, p(D|H₁)=(1/6)5(5/6)15≈8×10−6 ⇒ LR≈8 favours die. If H₁ true: log pθ₁ grows linearly in n.
  • Frequentist vs Bayes: freq. uses sup (best θ); Bayes averages (evidence). Inference ≠ prediction: ML predicts, DS finds out. Posterior needs prior p(θ); D−θ−D′ is a Markov chain.

L7 · Estimating information

  • Info quantities need p(x); only samples ⇒ density estimation then plug into formula. Types: 0 plug-in (discrete) · I parametric · II non-parametric · III variational.
  • Plug-in: p̂(xj)=#(X=xj)/n, plug into −Σp̂log p̂. Binning continuous = usually bad.
  • Mock Q2 recipes: (a) Gaussian estimator on X-shaped / non-linearly dependent data: Σ diagonal ⇒ Î=0 though dependent ⇒ unsuitable (model mismatch). (b) Non-param H(X): place kernel Kh on each xi, q(x)=(1/n)ΣKh(x−xi) (pick h by cross-validation), then Ĥ=−(1/n)Σilog q(xi) [or k-NN]. (c) I=H(Y)−H(Y|X) ≥ H(Y)+Ep[log q(y|x)] since Eplog p(y|x)−Eplog q(y|x)=D(p‖q)≥0 (Gibbs); LLN: E≈(1/n)Σlog q(yi|xi) for large n.
  • Parametric: fit qθ (θ*=argmax qθ(xⁿ)), H=−Eqθ*[log qθ*]; Gaussian: ½ln|2πeΣ|. Garbage in, garbage out (Gaussian fit to non-linear dependence gives I=0).
  • Non-parametric: H=−Ep[log q(x)]; kernel q(x)=(1/n)ΣKh(x−xi), Kh=(2πh²)−½exp(−(x−xi)²/2h²); tune h via cross-validation. k-NN (Kraskov): adaptive width, area A with K nearest neighbours, locally uniform; more accurate.
  • Variational: H=maxθĤθ(xⁿ) (estimation→optimisation). Barber-Agakov: I(X;Y) ≥ H(Y)+(1/n)Σlog qθ(yi|xi) (any q; Gibbs). Contrastive (van den Oord): positives from p(x,y), negatives from p(x)p(y) (shuffle); classifier fθ; I ≥ LCE=−E log[f(xi,yi)/Σj=1Mf(xj,yi)]; optimal f=p(x,y)/(p(x)p(y)).
  • Bias=⟨Î⟩−I; Variance=⟨(Î−⟨Î⟩)²⟩; both worsen with little data; cheap methods ⇒ more assumptions. Probabilistic numerics: estimation as inference.
  • Statistic T(x); sufficient if θ−T−X Markov chain. R={x:T(x)>k}. p-value=P under H₀ of T ≥ observed; significant if p<α (0.05). Critical value: α=∫tcrit∞pθ₀(T=t)dt. Null distribution hard; Wilks: 2logΛ→χ² as n→∞ (finite n: simulate). Report p-values but not only p-values.
  • Surrogate data: sample null empirically by randomising only the tested property. Independence: Î(X;Y), shuffle Y→YS, p = #{Î(X;YS)≥Î(X;Y)}/#surrogates. Triplet: statistic/null/surrogate.
  • Power analysis (sample size for effect): power=1−β=P(x∈R|H₁) depends on fixed θ∈Θ₁ & n. Simulate: pick n, µ>0; draw n samples from H₁; run NHST at α; repeat M times; power=fraction rejected. Increases with effect and n. Analytical: CDF/inverse CDF; non-central χ²(λ). Bias estimation: fit model p(x,y), compute true I, draw n samples M times, compare Î to I.

L8 · Information geometry

  • Euclid: s²=zᵀGz, G=I. Manifold: locally like Rⁿ; ds²=dxᵀg(x)dx. Polar: g=diag(1,r²). Statistical manifold: points=PDFs; coordinates matter (σ² vs precision Λ=Σ⁻¹).
  • Divergence D:M×M→[0,∞): D(p,q)≥0; =0 iff p=q; D(p,p+dp) positive-definite quadratic form. KL satisfies (Gibbs). Others: Bregman, f-divergences.
  • Projection: idempotent P=P∘P; Euclid: argmin‖v−w‖². I-projection qI*=argminq∈QD(q‖p): zero-forcing (q=0 where p=0), expectation wrt q, approximates complex with simple. M-projection qM*=argmin D(p‖q): zero-avoiding (q>0 where p>0), expectation wrt p ⇒ usable with data samples. Differ since KL asymmetric.
  • MLE = M-projection: D(p‖q)=−H(p)−Ep[log q] ≈ −H(p)−(1/n)Σlog q(xi); argmax Eplog q = argmin D(p‖q).
  • MI = M-projection onto factorisable F: I(X;Y)=minq∈FD(p‖q) (=−H(X,Y)+H(X)+H(Y); optimal f=p(x), g=p(y)). Cond.: I(X;Y|Z)=minq∈CD(p‖q), C={q:q(x|y,z)=q(x|z)}.
  • Pythagoras: r=M-projection of p on (dually flat) Q, q∈Q: D(p‖q)=D(p‖r)+D(r‖q) (also for I-proj). With F⊂C: I(X;Y,Z)=I(X;Y|Z)+I(X;Z) ⇒ MI chain rule.
  • Max entropy (Jaynes): among models with E[fi(X)]=αi, choose max H. Result: p(x)=Z⁻¹exp(−Σλifi(x)) (exponential family; Lagrangian: −1−log p+Σλifi=0), λ set to meet constraints. Maxent = I-projection of uniform u onto Q={E_q fi=αi} (D(q‖u)=−H(q)+const). More constraints ⇒ H(q₂*)≤H(q₁*).
  • Fisher information: D(θ‖θ+dθ)=½dθᵀI(θ)dθ+O(dθ³) (offset & 1st derivative vanish). I(θ)=−E[∂²log pθ(X)/∂θ²] (Hessian Ijk=−E[∂²log p/∂θj∂θk]) = natural metric; = peak sharpness of likelihood; = Var(score), score=∂log pθ/∂θ; = E[∂ilog p ∂jlog p] (first derivs only, autodiff). Gaussian (µ,σ): I=diag(σ⁻²,2σ⁻²).
  • Bias-variance: MSE(θ̂)=E[(θ−θ̂)²]=Bias²+Var (cross term=0 as θ fixed). Cramér-Rao: MSE ≥ b(θ)²+(1+b′(θ))²/I(θ); unbiased: Var ≥ 1/I(θ). Origin of trade-off is geometric.
  • Quick-reference: I-proj ⇒ KL(q‖p), q forced to 0 where p=0 (mode-seeking); M-proj ⇒ KL(p‖q), covers all p support (mass-covering), = MLE. Projecting Gaussian p onto diagonal-Σ Gaussians (Z₁⊥Z₂): M-projection matches marginals, I-projection is narrower. Fisher info large ⇒ sharp likelihood ⇒ low variance bound; KL curvature = I.
  • Unification: same formulae from communication (compression & transmission), hypothesis tests (LRT) and projections on statistical manifolds.
