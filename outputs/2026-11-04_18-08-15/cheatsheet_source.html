STATISTICAL INFORMATION THEORY — CHEATSHEET (side 1: Lectures 1–4)

LECTURE 1 · INTRODUCTION & PROBABILITY RECAP

  • Info theory = art of redundancy: remove it when it hurts (compression/source coding), add it when it helps (channel coding). Info & statistics = two sides of one coin. Course: source coding → channel coding → statistics/geometry.
  • Source coding: map data symbols → {0,1}; want short + easily decodable; frequent symbols get shorter words (e.g. B→0, R→10, W→11: 1.56 bit/px vs 3 one-hot).
  • Channel: BSC flips bit w.p. f. Repetition code R3: 0→000, 1→111, r = t + n; optimal decoder = Bayes: ŝ = argmaxs P(r|s)P(s) (here majority vote). pb = 3f² (1−f) + f³ ≈ 3f²: error O(f)→O(f²) but rate ÷3. Shannon: error-free comms at non-zero rate is possible (rate < C).
  • Logs: log=log₂, ln=loge; log(xy)=log x+log y; log(xⁿ)=n log x; logbx = logax / logab; log 1=0; log(x+y) does NOT simplify; ln2≈0.69; log(1/8)=−3.
  • Convex (“convex-down”, ∪): f(λx₁+(1−λ)x₂) ≤ λf(x₁)+(1−λ)f(x₂); prove via f″≥0 or convexity-preserving ops (affine map f(Ax+b); non-neg. weighted sum). log and −x log x are concave (∩).
  • RV X: Ω→E measurable fn. P(ω)≥0, P(Ω)=1. Discrete: pmf, Σp=1. Continuous: pdf, ∫p=1 (density can be >1). Notation: X rv, x realisation, 𝒳 alphabet.
  • Expectation Ep[f(X)] = Σx p(x)f(x); Var = E[X²]−µ². i.i.d. = independent + identically distributed.
  • Jensen (f convex ∪): E[f(x)] ≥ f(E[x]); (concave ∩ reverses: E[log x] ≤ log E[x]).
  • Gaussian N(µ,Σ): p(x) = (2π)−d/2|Σ|−1/2 exp(−½(x−µ)ᵀΣ⁻¹(x−µ)); 68.3/95.5/99.7% within 1/2/3σ.

LECTURE 2 · ENTROPY & SOURCE CODING THEOREM

h(x) = log 1/p(x)   (surprisal)  |  H(X) = Σ p(x) log 1/p(x) = E[h(X)]
  • Units: log₂ → bits; ln → nats. Binary entropy H₂(p) = −p log p − (1−p) log(1−p) (max 1 bit at p=½). Convention 0 log 0 = 0. Unlikely outcomes carry more info.
  • Bounds: 0 ≤ H(X) ≤ log|𝒳|. Min: Kronecker δ (pi=1). Max: uniform. Independent X,Y: h and H are additive: H(X,Y)=H(X)+H(Y).
  • Shannon axioms for surprisal i(p): (1) i(1)=0; (2) di/dp ≤ 0 (rarer = more surprising); (3) i(pq)=i(p)+i(q) ⇒ only i(p) = −logb p.
  • Guessing games: uniform ⇒ h(x)=#yes/no questions = binary-encoding length (63-game: 6 bit). Submarine: total info always log 64 = 6 bit however many misses (Σ log(64/63)+…+log(n+1)/n + log n). Info = probability-mass exclusion (Hartley). Design experiments with evenly probable outcomes.
  • Differential entropy H(X) = −∫f log f dx. Derived from bins Δ: H(XΔ )= −Σ Δf log f − log Δ (diverges as Δ→0; drop it). Can be negative; U[0,a]: H = log a (2H = volume).
  • Gaussian: h(x) = ln(σ√2π) + ½((x−µ)/σ)² (≈ scaled MSE: lower by moving µ→x or (sometimes) raising σ). H(N(µ,Σ)) = ½ ln|2πeΣ|   (1D: ½ ln 2πeσ² )
  • Entropy = generalised variance; ≈ log-volume of iso-probability contours.

Source coding theorem (SCT)

  • Code C: 𝒳→𝒟*; ℓ(x) codeword length; L=E[ℓ]. |𝒟|=2 binary, d-ary. Raw bit content = log|𝒳| (use ⌈log|𝒳|⌉, “extra bit” if not power of 2).
  • WLLN: Ȳₙ=(1/n)ΣXᵢ → µ in prob.; E[Ȳ]=µ, Var(Ȳ)=σ²/n. High-dim Gaussian: points in a thin shell, Std(r²)/E[r²]=O(1/√n)→0.
  • AEP: X₁..Xₙ i.i.d. ⇒ −(1/n) log p(x₁..xₙ) → H(X) (by LLN). All typical samples ≈ equiprobable.
  • Typical set Aε(n): 2−n(H+ε) ≤ p(xⁿ) ≤ 2−n(H−ε). (1) xⁿ∈A ⇒ |−(1/n)log p(xⁿ) − H| ≤ ε, p≈2−nH; (2) P(xⁿ∈A) > 1−ε; (3) |A| ≤ 2n(H+ε); (4) |A| ≥ (1−ε)2n(H−ε). So |A|≈2nH out of |𝒳|ⁿ. (Proofs: 3 by Σp=1≥|A|·2−n(H+ε); 4 by 1−ε<P(A)≤|A|2−n(H−ε).) Biased coin p: typical strings have ≈ fraction p of 1s (binomial vs pr(1−p)n−r tradeoff). Entropy = fraction of log-volume occupied: log|A|/log|𝒳|ⁿ = H/log|𝒳|.
  • SCT: for any ε>0, large n ⇒ ∃ invertible code with E[ℓ(Xⁿ)/n] ≤ H(X)+ε. Converse: no invertible code has L < H(X). (achievability + converse.)
  • Achievability proof: flag bit 0 + index in A (ℓ ≤ 1+⌈log|A|⌉ ≤ n(H+ε)+2) else flag bit 1 + index in 𝒳ⁿ (ℓ ≤ n log|𝒳|+2); L ≤ n(H+ε′), ε′=ε+ε log|𝒳|+2/n. Converse: sub-typical set C with |C|≈2n(H−κ) has P ≈ 2−nκ→0.

Proof: ℓmax tree has ≤ Dℓmax leaves; word of length ℓᵢ owns Dℓmax−ℓᵢ of them ⇒ ΣDℓmax−ℓᵢ ≤ Dℓmax. “Codeword supermarket”: short words cost more; budget =1. Satisfying Kraft means a prefix code with those lengths exists.

Needs ℓ integer in practice ⇒ round up ⌈−logD pᵢ⌉ (assumed continuous & equality in derivation). Duality: pᵢ ∝ D−ℓᵢ = “implicit probabilities” of a code.

  • Huffman: repeatedly merge the 2 least-probable symbols into one; read codes off the tree. Optimal: L(C*) ≤ L(C′) for any UD code. Ex: p={.25,.25,.2,.15,.15} → ℓ={2,2,2,3,3}, L=2.3.

Wrong code · cross-entropy · KL

H(p,q) = −Σ p log q  (len. of q-optimal code on p-data)
DKL(p‖q) = Σ p log (p/q) = H(p,q) − H(p) ≥ 0  (extra cost)
  • Gibbs’ inequality: DKL ≥ 0, =0 iff p=q. Proof: −D = Σp log(q/p) ≤ log Σ p·q/p = log 1 = 0 (Jensen, log concave); convex in q ⇒ unique minimum at p=q.
  • KL is asymmetric (not a distance); =∞ if ∃x: q(x)=0, p(x)>0. D(p‖u) = log|𝒳| − H(p) ⇒ H ≤ log|𝒳|. Ex: D(p₁‖p₂)=0.25, D(p₂‖p₃)=∞, D(p₃‖p₂)=0.5, D(p₃‖p₁)=1 bit. Continuous KL ≥0 too (log Δ cancels).
  • Gaussians: DKL(p‖q) = ½[σ²p/σ²q − 1 − ln(σ²p/σ²q) + (µp−µq)²/σ²q]; H(p,q) = ½ln 2πσ²q + [σ²p+(µp−µq)²]/2σ²q. Narrow Gaussians: KL grows faster with Δµ.
  • MLE: θ* = argmax p(x;θ); log-lik 𝓛=(1/n)Σ ln p(xᵢ;θ) → Ep[ln p(x;θ)] (n→∞) ⇒ ML = min KL = min code length. Gaussian mean: µ*=(1/n)Σxᵢ.
  • Good compressor = good predictor: code ℓ ⇒ q=2−ℓ/z, z=Σ2−ℓ (Kraft number ≤1). Extra cost Ep[ℓ−ℓ*] = log(1/z) + DKL(p‖q) ≥ 0; zero iff Kraft equality & p=q.

LECTURE 4 · JOINT ENTROPY & MUTUAL INFORMATION

  • Joint RVs = different partitions of Ω; p(x,y)=measure of X⁻¹(x)∩Y⁻¹(y). Marginal p(x)=Σyp(x,y); conditional p(x|y)=p(x,y)/p(y). Product p(x,y)=p(x|y)p(y); sum p(x)=Σp(x|y)p(y); Bayes p(x|y)=p(y|x)p(x)/p(y).
  • Independence: X⊥Y ⇔ p(x,y)=p(x)p(y) (⇒p(x|y)=p(x)); cond.: X⊥Y|Z ⇔ p(x,y|z)=p(x|z)p(y|z). Conditioning can create/destroy independence: Y=f(X),Z=g(Y): X⊥̸Z but X⊥Z|Y; Z=X⊕Y (fair coins): X⊥Z but X⊥̸Z|Y.
  • Bayesian network: p(X)=∏ₖ p(Xₖ|pak). Markov chain X−Y−Z: p(Xₜ|Xₜ₋₁..X₁)=p(Xₜ|Xₜ₋₁) (⇒X⊥Z|Y); order-p: depends on last p.
H(X,Y) = −Σ p(x,y) log p(x,y)   H(X|Y) = Σy p(y)H(X|Y=y)
Chain rule: H(X,Y) = H(X|Y) + H(Y) = H(Y|X) + H(X)
  • H(X|Y) ≥ 0 (disc.); ≤ log|𝒳|; =0 if X=f(Y); =H(X) if X⊥Y. Invariance: discrete H invariant under bijections (H(X|Y)=H(Y|X)=0 ⇒ H(X)=H(Y)).
  • Cond. KL: D(p(X|Y)‖q(X|Y)) = Σy p(y) D(p(X|y)‖q(X|y)) ≥ 0.
  • Stationary process (p(X₁..Xₜ)=p(X₁₊ₛ..Xₜ₊ₛ)). Entropy rate h = lim (1/n)H(X₁..Xₙ) = lim H(Xₙ|X₁..Xₙ₋₁) (equal for stationary); conditioning on more history never increases it; reaches h at Markov order p. Coin-in-a-box (flip w.p. p): h = H₂(p). Stream codes (Lempel–Ziv/zip) use entropy rate.
I(X;Y) = Σ p(x,y) log [p(x,y)/(p(x)p(y))] = DKL(p(X,Y)‖p(X)p(Y))
= H(X)+H(Y)−H(X,Y) = H(X)−H(X|Y) = H(Y)−H(Y|X)
  • Symmetric; I ≥ 0; I=0 ⇔ X⊥Y; I(X;Y) ≤ min{H(X),H(Y)} (discrete). Info doesn’t hurt: H(X|Y) ≤ H(X) (but H(X|Y=y) may exceed H(X)).
  • Cond. MI I(X;Y|Z)=H(X|Z)−H(X|Y,Z)=D(p(X,Y|Z)‖p(X|Z)p(Y|Z)) ≥ 0; =0 ⇔ X⊥Y|Z. MI chain rule: I(X,Y;Z) = I(X;Z) + I(Y;Z|X).
  • Data processing inequality: X−Y−Z ⇒ I(X;Z) ≤ I(X;Y) (I(X;Y,Z)=I(X;Z)+I(X;Y|Z)=I(X;Y)+I(X;Z|Y), last =0). MI invariant under bijections (even continuous).
  • Venn: H(X)=µ(A), H(X,Y)=µ(A∪B), H(X|Y)=µ(A\B), I=µ(A∩B). Co-information I(X;Y;Z)=H(XYZ)−H(XY)−H(YZ)−H(XZ)+H(X)+H(Y)+H(Z) can be negative.
  • Gaussian MI: I(X;Y) = −½ log(1−ρ²) = ½ log(σyy/σ²y|x) ; uncorrelated ≠ independent, MI captures non-linear dependence.
  • MI = bound on prediction: I(X;Y) = H(Y)+E[log p(y|x)] ≥ H(Y) + Ep(x,y)[log qθ(y|x)] (Gibbs); equality if p(y|x)∈Q at best θ. Mock exam 2(c): empirical avg (1/n)Σ log q(yᵢ|xᵢ) ≈ E[log q].

LECTURE 5 · CHANNEL CODES

  • DMC: input alphabet 𝒳, output 𝒴, p(y|x); extended channel p(yⁿ|xⁿ)=∏p(yᵢ|xᵢ). BSC(f): I(X;Y)=H(Y)−H(Y|X)=1−H₂(f) for uniform input (H(Y|X)=H₂(f)).
Capacity: C = maxp(x) I(X;Y)  (optimal p*(x) = capacity-achieving input)
Recipe: I = H(Y) − H(Y|X); H(Y|X)=Σ p(x)H(Y|X=x); parametrise p(X=1)=α, maximise over α∈[0,1]
  • Noisy typewriter (27 symbols, each → itself/2 neighbours w.p. ⅓): H(Y)=log27, H(Y|X)=log3, I=log9; use every 3rd letter ⇒ non-confusable inputs (disjoint output sets) ⇒ error-free. Channel AEP: 2nH(Y) outputs, 2nH(Y|X) per input ⇒ 2n(H(Y)−H(Y|X)) = 2nI distinguishable messages. Interpretation of C: max rate (bits/channel use) for reliable (arbitrarily small error) communication.
  • (n,K) block code: 2K codewords of length n; rate R=K/n. Decoder yⁿ→ŝ. Mean block error pB=Σp(s)p(ŝ≠s|s); maximal pBM=maxsp(ŝ≠s|s); bit error pb.
Noisy-channel coding thm: (1) ∀ε>0, R<C ∃ code (large n) with pBM<ε. (2) With pb tolerated, rates up to R(pb) = C/(1−H₂(pb)) achievable. (3) Rates above R(pb) NOT achievable.
  • Proof ingredients: (i) joint typicality Jε(n): xⁿ typical, yⁿ typical, (xⁿ,yⁿ) typical (each within ε of H(X), H(Y), H(X,Y)). Props: ① p(xⁿ,yⁿ)≈2−nH(X,Y); ② P(J)→1 (union bound on complements); ③ |J| ≤ 2n(H(X,Y)+ε); ④ independent x̃ⁿ,ỹⁿ~p(xⁿ)p(yⁿ): P(∈J) ≤ 2−n(I(X;Y)−3ε). (ii) random codes (sample 2nR words from p(xⁿ); average error; “weighing babies”: avg <δ ⇒ some code <δ). (iii) typical-set decoder: success iff exactly one s with (xⁿ(s),yⁿ) jointly typical. Errors: true xⁿ(s) not JT (→0 by ②) or another s′ JT: ≤(2nR−1)2−n(I−3ε) ≤ 2−n(I−R−3ε) →0 iff R<I−3ε (use p* ⇒ R<C−3ε). (iv) expurgation: drop worst half of words ⇒ pBM ≤ 2pB, rate R−1/n.
  • Error detection vs correction: R₂ detects 1 flip (01→?), R₃ corrects 1 flip (101→1).
  • Parity = XOR = sum mod 2. Hamming (7,4): n=2m−1=7, K=4 data, m=3 parity; 16 codewords; parity bits at positions 1,2,4 (powers of 2): p₁d₁p₂... layout p₁p₂d₁p₃d₂d₃d₄.

LECTURE 6 · PROBABILISTIC INFERENCE

  • Descriptive vs inferential stats (parameter estimation, hypothesis testing). Frequentist: true θ exists, behaviour over repeated experiments. Bayesian: beliefs about θ updated by data.
  • NHST: H₀ (null, “business as usual”) vs H₁; rejection region R: x∈R ⇒ reject H₀. Simple: θ=θ₀ (point); composite: θ∈Θ₀ (region); nested: H₀ fixes a parameter of H₁ (a=0 vs a≠0).
  • Type I (false positive) α = P(x∈R|H₀); Type II (false negative) β = P(x∉R|H₁); power = 1−β. Mnemonic: boy who cried wolf (I = cried wolf with none). Can only reject / fail to reject H₀ — never “accept”.
Neyman–Pearson lemma: for simple H₀:θ₀ vs H₁:θ₁, the most powerful test of size α rejects when Λ(x) = pθ₁(x)/pθ₀(x) > k, with k s.t. pθ₀(x∈R)=α.
  • Proof idea: any R′ with same α: R\R′ and R′\R have equal H₀-probability φ; on R\R′ pθ₁ > kpθ₀ (mass > φk), on R′\R < kpθ₀ (< φk) ⇒ pθ₁(R′) < pθ₁(R): R′ has less power.
  • Likelihood ratio (LRT) Λ = supθ∈Θ₁ pθ(x) / supθ∈Θ₀ pθ(x); log Λ = log pθ₁*(x) − log pθ₀*(x) optimal for simple H (N-P); for composite w/ monotone likelihood (Karlin–Rubin); otherwise often good, not always optimal. i.i.d.: log Λ = Σ[log pθ₁*(xᵢ)−log pθ₀*(xᵢ)] → nE[…]. log Λ = “evidence” for H₁ (frequentist). Mock exam 4: plug in MLEs of λ (exp: λ̂=1/x̄) and σ² (half-normal: σ̂²=x̄²=mean of squares) into Σ log(q/p).
  • MI as LR test (H₀: p=f(x)g(y) vs H₁: joint): supH₁ log-lik = −nH(X,Y); supH₀ = −n(H(X)+H(Y)) (using E[log pθ] = −H − DKL). I(X;Y) = (1/n) E[log Λ] = E[log p(x,y)/(p(x)p(y))] — MI = evidence for joint over factorised model.

Bayesian inference

p(θ|D) = p(D|θ)p(θ)/p(D)  (posterior = likelihood × prior / evidence)
Evidence p(D) = ∫ p(D|θ)p(θ)dθ = Ep(θ)[p(D|θ)]   (“replace sups with sums”)
  • Prediction: p(D′|D) = ∫p(D′|θ)p(θ|D)dθ (D−θ−D′ Markov chain). MAP: θ = argmax p(D|θ)p(θ). Posterior = inverse probability problem.
  • Gaussian mean (known σ², prior N(µ₀,σ₀²)): µ₁ = (σ₀²x + σ²µ₀)/(σ₀²+σ²),  1/σ₁² = 1/σ₀² + 1/σ².
  • Bayes factor BF = p(D|H₁)/p(D|H₀); posterior odds p(H₁|D)/p(H₀|D) = BF × p(H₁)/p(H₀) BF≫1 for H₁, ≈1 inconclusive, ≪1 for H₀ (can support either). p(H|D)=p(D|H)p(H)/p(D), p(D)=Σp(D|Hᵢ)p(Hᵢ).
  • Coins: H₀:q=½ ⇒ p(D|H₀)=2−n; H₁:q~U(0,1) ⇒ p(D|H₁)=∫qh(1−q)n−hdq = h!(n−h)!/(n+1)!; BF = h!(n−h)!2n/(n+1)!. Short n inconclusive; h/n≈½ ⇒ BF→0.
  • Occam’s razor: p(D|H) ≈ p(D|wMP,H) × σw|D/σw = best-fit likelihood × Occam factor (low if big prior range but data fits tiny part: flexible models are penalised).
  • MDL (Shannon’s razor): L(D) = L(Hᵢ) + L(w*|Hᵢ) + L(D|w*,Hᵢ). Simple H₁: short params, poor fit; complex H₃: opposite; H₂ best tradeoff.

LECTURE 8 · INFORMATION GEOMETRY

  • Manifold: locally like ℝⁿ; small steps ds²=dxᵀg(x)dx with metric g (polar: g=diag(1,r²)). Euclid: s²=zᵀGz, G=I. Statistical manifold: points = PDFs; same manifold, different coordinates (variance vs precision Λ=Σ⁻¹).
  • Divergence D: ① D(p,q)≥0; ② D=0 iff p=q; ③ D(p,p+dp) positive-definite quadratic form. KL satisfies all (others: Bregman, f-divergences).
  • Projection: idempotent P=P∘P (Euclid: Proj v = argmin‖v−w‖²).
I-projection: q*I = argminq∈Q DKL(q‖p) (zero-forcing; E wrt q — approximate complex p by simple q)
M-projection: q*M = argminq∈Q DKL(p‖q) (zero-avoiding; E wrt p — real data)
  • MLE = M-projection: D(p‖q) = −H(p) − E_p[log q] ≈ −H(p) − (1/n)Σ log q(xᵢ).
  • MI = M-projection onto factorisable F={q: q(x|y)=q(x)}: I(X;Y) = minq∈F DKL(p‖q) (min at f=p(x), g=p(y) by Gibbs ⇒ −H(X,Y)+H(X)+H(Y)). Cond. MI: M-proj onto C={q(x|y,z)=q(x|z)}: I(X;Y|Z).
  • Pythagoras: r = M-proj of p on Q, q∈Q ⇒ D(p‖q) = D(p‖r) + D(r‖q) (also I-proj; needs “dually flat” Q). Applied to F⊂C ⇒ I(X;Y,Z)=I(X;Y|Z)+I(X;Z) (= MI chain rule).
  • Max-entropy principle (Jaynes): given E[fᵢ(X)]=αᵢ, choose max H subject to them. Lagrange: ℒ=−Σp log p+Σλᵢ(Σp fᵢ−αᵢ) ⇒ p(x) = (1/Z) exp(−Σᵢ λᵢ fᵢ(x))  (exponential family) λ set s.t. constraints hold. Maxent = I-projection of uniform u on Q={E_q[fᵢ]=αᵢ} (D(q‖u)=−H(q)+log u). More constraints ⇒ H(q₂*) ≤ H(q₁*).
  • Fisher information: D(θ‖θ+dθ) ≈ ½dθᵀ I(θ) dθ (offset & 1st derivative vanish by Gibbs). I(θ) = −E[∂² log pθ(X)/∂θ²] = Var(score) = E[(∂ log pθ/∂θ)²], score = ∂ log pθ/∂θ Vector: Ijk = −E[∂²log p/∂θⱼ∂θₖ] (Hessian) — natural metric; high I = sharp likelihood peak, KL grows fast. Gaussian (µ,σ): I = diag(σ⁻², 2σ⁻²).
  • Bias–variance: MSE(θ̂)=E[(θ−θ̂)²]=Bias² + Var (cross term vanishes since E[θ̂−E θ̂]=0). Cramér–Rao: MSE(θ̂) ≥ b(θ)² + (1+b′(θ))²/I(θ) (b = bias). More curved pθ ⇒ easier estimation.
  • Wrap-up: same formulae derived 3 ways — optimal communication, optimal hypothesis tests, projections on manifolds. Info theory sets limits of what is possible in ML.
